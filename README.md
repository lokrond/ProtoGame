# VOIDSTAR


Support d'entrainement script C++ sur build Unreal Engine ~5.2
Jeu type ACTION TPS avec compétence, blocage (perfect parry), téléportation (blink), tire de projectile (shooter) et compétence ultime (black hole) avec simulation physics.
Système IA Pathfinding Survival (vague d'ennemi convergeant vers le joueur) avec aisance de fuite (précision affaibli sur joueur dos aux ennemis)
Système de tag appliqué en système de porte Doom-like (color tag), tag de débuff (DoT sur projectile joueur), tag de buff (épine, immunité perfect parry)
